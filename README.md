# Portfolio de Desarrollo Frontend Inclusivo

Este proyecto constituye mi carta de presentación como desarrolladora web. En él he volcado mi aprendizaje técnico, pero sobre todo mi visión sobre la importancia de la accesibilidad digital en el mundo actual.

## Propósito del proyecto

El objetivo de este sitio es demostrar cómo el diseño y la tecnología pueden trabajar juntos para eliminar barreras. Mi formación en animación sociocultural y mi experiencia profesional trabajando con personas con discapacidad me han dado una perspectiva práctica sobre la diversidad funcional. 

He construido este portfolio bajo la premisa de que una web solo está bien hecha si es usable para todo el mundo, independientemente de sus capacidades.

## Características técnicas y accesibilidad

Para garantizar una navegación fluida y universal, he implementado las siguientes medidas:

- **Semántica HTML:** Uso de etiquetas estructurales para facilitar la interpretación por parte de tecnologías asistivas.
- **Cumplimiento WCAG:** Cuidado exhaustivo en el contraste de colores y legibilidad tipográfica.
- **Navegación por teclado:** Gestión del foco para asegurar que la web sea totalmente operable sin necesidad de ratón.
- **Diseño Adaptativo:** Optimización completa para dispositivos móviles y pantallas de pequeño formato.
- **Preferencias de usuario:** Implementación de modo oscuro automático basado en la configuración del sistema.

## Tecnologías utilizadas

- HTML5 y CSS3 (Flexbox y Variables CSS).
- JavaScript para la lógica de interacción y validación.
- DevIcon para la iconografía técnica de las habilidades.
- Normalize.css para garantizar la consistencia entre diferentes navegadores.

## Sobre mi enfoque

Entiendo el desarrollo Frontend como una extensión de mi labor social previa. Mi capacidad para diseñar pensando en todas las capacidades no es solo una decisión técnica, sino una filosofía de trabajo que busca humanizar el código y asegurar que la tecnología sea una herramienta de inclusión.
